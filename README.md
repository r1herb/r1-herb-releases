# R1 Herb ตัวติดตั้ง

ที่เก็บตัวติดตั้งโปรแกรม R1 Herb สำหรับ Windows โปรแกรมที่ติดตั้งไว้แล้วจะตรวจรุ่นใหม่จากที่นี่และอัปเดตเอง

ที่นี่มีเฉพาะไฟล์ตัวติดตั้ง ไม่มีซอร์สโค้ด ไม่มีข้อมูลยาหรือข้อมูลผู้ใช้ รุ่นใหม่สร้างจากระบบ CI ของโปรเจกต์โดยอัตโนมัติ ไม่ต้องอัปโหลดเอง

ติดตั้งครั้งแรก: เปิดหน้า Releases แล้วดาวน์โหลด `R1-Herb-Setup-<รุ่น>.exe` ของรุ่นล่าสุด
